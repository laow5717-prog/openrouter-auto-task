# PRD: 账号管理增强 - 导出数据与信用卡关联查看

## Goal
账号管理页面增加数据导出功能（支持搜索结果导出和选中导出），导出数据包含关联的信用卡信息；页面内可快捷查看每个账号绑定的信用卡。

## Requirements

### 1. 信用卡关联查询
- 后端提供按邮箱查询已绑定信用卡的 API
- card_bindings 表通过 bound_to_email 字段关联账号

### 2. 账号表格增加勾选和信用卡预览
- 表格增加复选框列（全选/单选）
- 表格增加"绑定卡片"列，显示卡片数量，点击可展开查看详情
- 卡片详情以弹窗展示：卡号后4位、状态、绑定时间

### 3. 数据导出
- 支持两种导出模式：导出当前搜索结果 / 导出选中行
- 导出 Excel 包含列：邮箱、CF密码、邮箱密码、状态、时间、绑定的信用卡信息
- 信用卡信息包含：卡号后4位、完整卡号、持卡人、状态

## Acceptance Criteria
- [ ] 账号表格有复选框，支持全选和单选
- [ ] 账号表格显示每个账号绑定的卡片数量，可点击查看详情
- [ ] 点击卡片数量弹出弹窗显示绑定的信用卡列表
- [ ] 可导出当前搜索结果为 Excel（含信用卡数据）
- [ ] 可导出选中行为 Excel（含信用卡数据）
- [ ] 导出的 Excel 包含完整信用卡信息
- [ ] 现有功能不受影响
