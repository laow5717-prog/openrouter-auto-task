# PRD: 前端后台管理系统升级

## Goal
将现有前端升级为合格的后台管理系统，支持表格分页和多维度筛选。

## Requirements

### 1. 后端 API 分页支持
- `/api/accounts` 支持 `page`, `page_size`, `status`, `keyword`, `date_from`, `date_to` 参数
- `/api/card/status` 支持 `page`, `page_size`, `status`, `keyword` 参数
- 返回 `{ data: [...], total, page, page_size }` 格式

### 2. 账号管理页
- 分页控件（上一页/下一页/页码/每页条数选择）
- 筛选栏：关键词搜索（邮箱）、状态下拉筛选、时间范围筛选
- 筛选条件变化时自动重置到第 1 页

### 3. 绑卡记录页
- 分页控件
- 筛选栏：状态下拉筛选（全部/成功/失败/待处理）、关键词搜索（卡号/绑定账号）

### 4. 前端通用组件
- 可复用的分页逻辑
- 统一的表格加载/空状态样式

## Acceptance Criteria

- [ ] 账号列表支持分页，默认每页 20 条
- [ ] 账号列表支持按状态、邮箱关键词、时间范围筛选
- [ ] 绑卡记录支持分页，默认每页 20 条
- [ ] 绑卡记录支持按状态、关键词筛选
- [ ] 筛选条件变更时自动回到第 1 页
- [ ] 表格有加载态和空状态提示
- [ ] 分页信息显示总条数和当前页范围
- [ ] 现有功能不受影响（启动任务、上传 Excel、实时监控等）
